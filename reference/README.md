# Reference

Material about the real thing being modelled:
- **Photos** go in [photos/](photos/): side, front, top and rear views are most useful. Claude can read images and use them to judge proportions.
- **Real-world sizes** go in a table here: real value, plus the scaled value if the project has a scale. `/kickoff` fills it in.
- **Hardware STEP files** (e.g. from McMaster-Carr) can go in `hardware/`. Claude can import them into the design to check fits.
