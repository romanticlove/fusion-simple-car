# Claude working rules (Fusion + 3D-print project)

Hobby projects modelled in Autodesk Fusion by Claude through Python scripts and printed on an FDM printer.
"Works and looks right" is the bar. Keep things simple, iterate fast, don't over-engineer.
The project itself is described in the root `CLAUDE.md` (`## Project`).

## File ownership (keeps template updates merge-conflict free)
Every file has exactly one owner. **Never edit a template-owned file while working on a project.** If a template file
needs a change, tell the user. It gets fixed in the template repo and pulled in (see `template/README.md`).

| Template-owned (edit only in the template repo) | Project-owned (template never changes them after the copy) |
|---|---|
| `template/**`: rules, `lib/`, `assembly.py`, `fit_test.py` | `CLAUDE.md` (imports these rules, plus `## Project`) |
| `.claude/skills/{kickoff,new-part,fit-fix}/` | `README.md`, `layout.py`, `hardware.md`, `decisions.md` |
| `.claude/settings.json`, `.mcp.json`, `.gitignore` | `parts/**`, `reference/**`, `exports/` (ignored) |

- Project-specific permissions go in `.claude/settings.local.json` (git-ignored), not `settings.json`.
- Project-specific skills go in `.claude/skills/<new-name>/`. Never put them inside the template's skill folders.
- Project-specific helpers go in `parts/_lib/` (e.g. `parts/_lib/wheels.py`), not `template/lib/`.
- Fits: template defaults live in `template/lib/fusion_helpers.py` `FIT_DEFAULTS`. A project overrides only the keys it
  needs in `layout.py` `FIT`. Read fits with `F = fh.fits(L)`.

## How we work
1. **Numbers before modelling.** Before building around a component (motor, battery, bearing), do the quick maths:
   torque, weight, speed, size, bed fit. Write the result, the risk and a plan B in `decisions.md`.
2. **Layout first.** Overall sizes, part positions and every connection between parts (screw holes, pins,
   shafts) live in `layout.py`. Part scripts read them from there, never hard-code them.
   Both sides of a connection read the same `INTERFACES` entry.
3. **One script per part:** `parts/<part-name>/<part_name>.py`. The repo is the source of truth, so no throwaway modelling scripts.
   - Part-only sizes go in the `P` dict at the top (mm). To change the part, edit `P` and re-run.
   - The docstring states the print orientation.
   - Add it to `layout.PARTS`.
4. **Check in Fusion, not on the printer.** After a build: screenshot (iso plus the ortho view that matters),
   then run `template/assembly.py` to lock the parts and report collisions between them. Show the user and adjust.
5. **Export** only once the user is happy: `fh.export(comp, "<name>")` → `exports/<name>.3mf`.
6. **Fits come from the fit test.** The first print of a project is `template/fit_test.py`.
   Add the project's hardware rows in `layout.FIT_TEST_HOLES`. Put measured results in `layout.FIT`.
   When a printed part doesn't fit, fix the number (/fit-fix), don't patch by eye.

Skills: `/kickoff` (start a project), `/new-part <name>`, `/fit-fix <problem>`.

## Fusion connection
- Fusion's built-in MCP server (`fusion` in `.mcp.json`, `http://127.0.0.1:27182/mcp`). Fusion must be running with a design open.
- Run repo scripts through `fusion_mcp_execute` (featureType `script`) with this loader. Don't paste whole scripts:
  ```python
  import importlib.util
  def run(context):
      spec = importlib.util.spec_from_file_location("part", r"<absolute path to script>")
      m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m); m.run(context)
  ```
- Scripts define `run(context)`. Don't wrap it in try/except; let errors surface.
- `fusion_mcp_read` (screenshot) shows the result.
- Every part is its own component, made with `fh.fresh_component(name)`, which deletes and rebuilds it on each run.
- Cuts must only touch the part's own bodies. `fh.extrude(op="cut")` does this. For a hand-made cut, set `participantBodies = fh.own_bodies(comp)`.
- Don't close, save, or open documents, or delete components a script didn't create, without asking.

## Libraries (`template/lib/`)
- `fusion_helpers.py`: mm-based sketch/extrude helpers, temporary-solid modelling
  (`cyl`, `box`, `hex_x`, `union`/`subtract`/`intersect`, `add_body`), `overlap_mm3`, `lock_assembly`, `fits`, `export`.
  Prefer temporary solids for primitive-heavy parts (housings, shafts): fast and no timeline clutter.
- `gears.py`: involute spur outlines, D-bores, and face (crown) gears generated by rolling the pinion.

## Scale
- Appearance sizes = real size ÷ scale.
- Motor, servo, screw, bearing and shaft fits use **real** sizes. Never scale these.

## Print-friendly defaults (0.4 mm nozzle)
- Walls 1.2–1.6 mm, small cosmetic detail ≥ 0.8 mm.
- Fit clearance from `fh.fits(L)` (0.2 mm per side until the fit test says otherwise).
- Avoid overhangs steeper than 45°, and design so parts print without supports where possible.
- Respect the bed size in `## Project`. Split bigger parts and join them with pins or tabs plus glue.
- PLA/PETG for parts, TPU for tires and grips. Keep moving models light.
